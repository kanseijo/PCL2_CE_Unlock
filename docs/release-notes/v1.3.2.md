## PCL2_CE_Unlock v1.3.2

> **非官方第三方工具**，与 PCL / PCL 社区版、PCL-Community、龙腾猫跃均无关联。
> 本项目**不含 PCL 的任何代码或二进制文件**。

### 本版修复

**1. 修复"已打过补丁"误报（重要）**

此前用 3 字节特征（`0A 17 2A`）在整份 exe 里搜索来判断"是否已打补丁"。官方启动器是 20 MB+ 的
.NET 单文件包，内部 IL 流里本来就会大量出现这种极短序列，实测官方原版 x64/ARM64 各命中 5 处以上——
于是**未打补丁也被标记成"已打过补丁"**，还会误触发"再次打补丁不会重复生效"的提示。

现改为**精确判定**：读取 5 个目标方法的真实方法体逐一比对（`PatchEngine.CountApplied`），
并加了基于 `文件长度 + 修改时间` 的缓存，避免菜单刷新时反复解析整个包。
三态均已回归验证：官方原版不显示、打完补丁显示、还原后消失。

**2. 修复 `--restore` / `--shortcut` 在非交互环境崩溃**

这两条命令末尾会等待按键，而 `Console.ReadKey()` 在 stdin 被重定向（管道、计划任务、CI）时会抛
`InvalidOperationException`，进程直接以 134 退出。现在检测到输入被重定向就跳过等待，命令行调用退出码为 0。

### 压缩包结构

解压后**直接得到 `PCL2_CE_Unlock/` 文件夹**（自 v1.3.1 起包内保留顶层目录），无需手动新建。

```
PCL2_CE_Unlock/
├─ PCL2_CE_Unlock.exe                 主程序
├─ PCL2_CE_Unlock.dll / .deps.json / .runtimeconfig.json
├─ dnlib.dll
├─ hook/PCL2_CE_Unlock.Hook.dll       注入组件 + MonoMod/Mono.Cecil
├─ README.md
└─ THIRD-PARTY-NOTICES.txt
```

校验和见附件 `PCL2_CE_Unlock.zip.sha256`。

### 快速使用

1. 把解压出的 `PCL2_CE_Unlock` 文件夹放进**你的 PCL 目录**（启动器在它的上一级）；
2. 运行 `PCL2_CE_Unlock.exe`，它会自动识别上级目录里的启动器（按内容识别，改名/中文名都行）；
3. `3)` 打补丁（就地替换 + 自动备份）或 `4)` 以注入方式启动（官方 exe 保持原样）。

运行要求：**.NET Desktop Runtime**（能运行 PCL-CE 就说明已具备）。

### 解锁范围（只做三件事）

| 目标 | 效果 |
| --- | --- |
| 地区限制判定 | 解除"所在国家或地区不可用" |
| 大陆环境判定 | 任何环境都走**可跳过**的正版劝导，不再硬拦启动 |
| 首次建档限制 | 首次启动即可选「第三方验证 / 离线登录」 |

### 明确**不改动**

- `McLaunchPrecheck`（正版购买劝导 / 试玩 / 返回逻辑）
- `ProfileService.get_HasMicrosoftProfile`（劝导入口条件）

两者逐字节未改动，打补丁时会自动校验。**请支持正版 Minecraft。**

### 已知限制

- 只针对 **PCL-CE v2.15.1** 验证；上游改名/改结构会导致失败（打补丁会中止、注入版会写日志提示）；
- 补丁版替换后，上游自动更新会覆盖它；
- 实例级"登录方式 = 要求正版验证"仍会拦截（用户自设项）。

### 安全与可逆

打补丁前会先写临时文件并自校验（文件长度、包清单、5 个目标、劝导两方法未改动），通过后才替换；
原文件保存为 `<原文件名>.<时间戳>.原版.bak`，还原时换下的补丁版保存为 `…补丁版.bak`。
菜单 `5)` 可一键还原。
